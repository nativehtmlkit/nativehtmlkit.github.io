HTML and CSS profile (generated reference)¶

Generated from nativehtmlkit-host 1.0.3 in headless mode. CSS profile ui4me-desktop-1.0 (host.hello capabilities css_profile: ui4me-desktop-1.0). Every value below is the host's own answer to a wire-v1 request; see the HTML and CSS support guide for explanations and caveats. Headless mode exercises parsing, style, layout and document state, not native painting, input or screen readers.

Regenerate: python3 scripts/docs/generate-html-css-reference.py --host PATH (--check verifies).

2. CSS properties (get_computed_style)¶

Each name was asked of get_computed_style on a <div>. supported: the host computes it (this does not prove every value renders natively); unsupported: excluded by the profile (feature id shown; declarations are parsed and ignored); invalid: not a property name the engine knows. inh marks inherited properties.

  • Box model and sizing — supported: display, box-sizing, width, height, min-width, min-height, max-width, max-height, margin, margin-top, margin-inline, margin-block, padding, padding-top, padding-inline, padding-block, aspect-ratio, inline-size, block-size, overflow, overflow-x, overflow-y, overflow-clip-margin, visibility inh, field-sizing, contain, contain-intrinsic-size, content-visibility, container-type, container-name.
  • Positioning — supported: position, top, right, bottom, left, inset, inset-inline, z-index, float, clear, isolation, anchor-name, position-anchor, position-area. Not supported: position-try (unsupported: css.property.position-try).
  • Flexbox and grid — supported: flex, flex-direction, flex-wrap, flex-flow, flex-grow, flex-shrink, flex-basis, order, justify-content, justify-items, justify-self, align-content, align-items, align-self, place-content, place-items, place-self, gap, row-gap, column-gap, grid-template-columns, grid-template-rows, grid-template-areas, grid-auto-flow, grid-auto-columns, grid-auto-rows, grid-column, grid-row, grid-area.
  • Multi-column and fragmentation — supported: columns, column-count, column-width, column-gap, column-rule, column-span, column-fill, break-before, break-after, break-inside, orphans inh, widows inh.
  • Tables and lists — supported: table-layout, border-collapse inh, border-spacing inh, caption-side inh, empty-cells inh, vertical-align, list-style, list-style-type inh, list-style-position inh, list-style-image inh, counter-reset, counter-increment. Not supported: counter-set (unsupported: css.property.counter-set).
  • Text and fonts — supported: color inh, font, font-family inh, font-size inh, font-weight inh, font-style inh, font-stretch inh, font-variant, font-variant-caps inh, font-variant-numeric inh, font-feature-settings inh, font-variation-settings inh, font-optical-sizing inh, font-kerning inh, font-synthesis, line-height inh, letter-spacing inh, word-spacing inh, text-align inh, text-align-last inh, text-indent inh, text-transform inh, text-decoration, text-decoration-line, text-decoration-style, text-decoration-color, text-decoration-thickness, text-underline-offset inh, text-underline-position inh, text-shadow inh, text-overflow, text-wrap, text-wrap-mode inh, text-wrap-style inh, white-space, white-space-collapse inh, word-break inh, overflow-wrap inh, hyphens inh, hyphenate-character inh, tab-size inh, line-clamp, -webkit-line-clamp, direction inh, unicode-bidi, writing-mode inh, text-orientation inh, text-combine-upright inh, quotes inh. Not supported: font-size-adjust (unsupported: css.property.font-size-adjust), text-decoration-skip-ink (unsupported: css.property.text-decoration-skip-ink), -webkit-text-stroke (unsupported: css.property.-webkit-text-stroke), -webkit-text-fill-color (unsupported: css.property.-webkit-text-fill-color), initial-letter (unsupported: css.property.initial-letter).
  • Backgrounds, borders and effects — supported: background, background-color, background-image, background-position, background-size, background-repeat, background-clip, background-origin, background-attachment, background-blend-mode, border, border-width, border-style, border-color, border-radius, border-image, border-top-left-radius, outline, outline-offset, box-shadow, opacity, filter, backdrop-filter, mix-blend-mode, clip-path, mask, mask-image, object-fit, object-position, image-rendering inh, accent-color inh, caret-color inh, color-scheme inh, appearance. Not supported: shape-outside (unsupported: css.property.shape-outside), image-orientation (unsupported: css.property.image-orientation), corner-shape (unsupported: css.property.corner-shape).
  • Transforms, transitions and animations — supported: transform, transform-origin, translate, rotate, scale, perspective, transform-style, backface-visibility, transition, transition-property, transition-duration, transition-timing-function, transition-delay, transition-behavior, animation, animation-name, animation-duration, animation-timing-function, animation-iteration-count, animation-direction, animation-fill-mode, animation-play-state, animation-delay. Not supported: animation-timeline (unsupported: css.property.animation-timeline), view-transition-name (unsupported: css.property.view-transition).

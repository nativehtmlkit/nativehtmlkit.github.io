Wire v1 tables (generated)¶

Parameters come from the JSON Schemas in ../v1/schemas/ (generated from the Rust serde types); result members and golden errors come from the runtime golden ../v1/conformance/golden.json (342 cases, host 1.0.3, headless; native GUI behavior is qualified separately). The golden records the JSON kind of each top-level member of the results it observed; members that only appear in other situations (or on a native desktop) are not listed. The schemas and the golden are the source of truth; the protocol reference explains semantics.

Regenerate with python3 scripts/docs/generate-wire-tables.py (--check verifies).

Python SDK API reference¶

Reference for nativehtmlkit 0.1.2 (bundles NativeHTMLKit Core 1.0.3, public wire protocol v1; Python 3.10+). Everything listed here is importable from nativehtmlkit unless noted.

from nativehtmlkit import Application

def main() -> None:
    with Application.start(name="Hello") as app:
        window = app.open_html('<button id="go">Go</button><p id="out">Ready</p>')
        window.document.on("click", lambda event: window.document.set_text("out", "Clicked"), element="go")
        app.run()

if __name__ == "__main__":
    main()

The object model is Application → Window → Document → Node. The Rust host owns windows, rendering and input; Python owns logic and talks to the host over a local, authenticated connection.

Rules that apply everywhere¶

  • Two processes. Application.start() re-runs your script as the host's backend. Keep side effects inside main(), after start(). See lifecycle.
  • Thread-safe. Any method may be called from any thread. Callbacks run on SDK threads (threading summary).
  • Generation-bound handles. A replaced, unloaded or closed document, its nodes and its window raise StaleDocumentError locally.
  • Text vs markup. set_text/set_value never parse HTML. replace_html/insert_html parse trusted markup only; escape user data with html.escape. See security.
  • Headless. With NATIVEHTMLKIT_TEST_MODE=1 everything except native services works without a desktop; those raise RpcError -32001.
